# StreamLite 🎬

A Netflix-inspired Android application built using Kotlin and TMDB API.

## Features
- Netflix-style UI
- Real-time movie data from TMDB API
- Movie detail screen
- Watchlist functionality
- Splash screen
- Smooth animations

## Tech Stack
- Kotlin
- Retrofit
- Glide
- RecyclerView
- SharedPreferences
- XML
